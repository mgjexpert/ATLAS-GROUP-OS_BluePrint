# Atlas Executive V1

Atlas Executive is the first human executive surface of Atlas Group OS.

## API

- `GET /api/v1/group-os/executive/brief`
- `GET /api/v1/group-os/executive/decision-queue`
- `POST /api/v1/group-os/executive/delegations`

## Brief

Returns one organization-scoped snapshot of:

- business units, branches and teams;
- projects and project status;
- task status and blocked/review workload;
- pending approvals;
- proposed decisions;
- active agents and Agent Pack assignments;
- recent Runtime runs and execution jobs;
- budgets and recorded usage.

The brief is built from canonical database state, not generated by an LLM.

## Decision queue

Combines:

- pending ApprovalRequests;
- proposed GovernanceDecisions.

The API does not auto-approve or auto-decide anything.

## Delegation

A human executive can delegate a real task to:

- one Team; or
- one Agent in the current tenant.

Delegation creates a `portfolio.tasks` record with audit metadata. It does not directly invoke the agent. Execution/orchestration of delegated tasks will be connected after Atlas.DG/task orchestration is introduced.
